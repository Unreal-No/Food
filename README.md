# Virtual Storefront

ร้านค้าออนไลน์ที่ตั้งค่าเองได้ (คาเฟ่ / ร้านอาหาร / ร้านค้า) — แบบระบบเต็มอยู่ที่ [docs/DESIGN.md](docs/DESIGN.md)

## เริ่มใช้งาน

```bash
npm install
npm run dev        # http://localhost:3000  (สร้าง DB + ข้อมูลตัวอย่าง 2 ร้านอัตโนมัติ)
```

| หน้า | URL |
|---|---|
| รวมร้าน | `/` |
| หน้าร้าน | `/mellow-bean`, `/baan-som` |
| หลังบ้าน | `/admin` |

### บัญชีทดลอง (dev)
| ชื่อผู้ใช้ | รหัส | บทบาท |
|---|---|---|
| `admin` | `admin` (หรือ `ADMIN_PASSWORD`) | ผู้ดูแลระบบ ทุกร้าน |
| `mellow` / `baansom` | `mellow1234` / `baansom1234` | เจ้าของร้าน |
| `mellow-kitchen` | `kitchen1234` | ครัว (เห็นแค่จอครัว) |
| `baansom-cashier` | `cashier1234` | แคชเชียร์ |

## ทำแล้ว (P0)
- หน้าร้านตามธีมของร้าน, หมวดหมู่ + scroll-spy, การ์ดเอียงตามเมาส์
- เลือกแบบย่อย (ร้อน/เย็น, S/M/L) + กลุ่มตัวเลือกเสริม (ขั้นต่ำ/สูงสุด/บวกราคา/ของหมด)
- ตะกร้า → สั่งซื้อ (ทานที่ร้าน/กลับบ้าน) → PromptPay QR ตามยอด → ติดตามสถานะ
- หลังบ้าน: ภาพรวมยอดขาย, ออเดอร์ (ยืนยันเงิน → ทำ → พร้อม → ส่งมอบ), สินค้า + variants + สต็อก, หมวดหมู่, กลุ่มตัวเลือก, ธีม/เวลาเปิด/PromptPay
- ราคาคำนวณใหม่ที่ server ทุกครั้ง, ตัดสต็อกใน transaction

## ทำแล้ว (P1 · 3D)
- ตัวดูสินค้า 3D: ลากหมุน, หยิก/เลื่อนซูม, หมุนอัตโนมัติ, ปุ่มกลับมุมเดิม — โหลด three.js เฉพาะตอนเปิดสินค้า
- **Live preview**: เลือก ร้อน/เย็น/ปั่น → แก้วเปลี่ยน, เพิ่มวิป/ไข่มุก/ไข่ดาว → โผล่ในโมเดล, พิเศษ → ขยายจาน
- โมเดลสำเร็จรูป 6 แบบ (แก้วร้อน, แก้วเย็น, จานข้าว, ชามซุป, ครัวซองต์, เค้ก) ปรับสี/ชิ้นส่วนได้ ไม่ต้องมีไฟล์
- รองรับไฟล์ `.glb` (node `opt_*` = ชิ้นส่วนเสริม, ชื่อ material = คีย์สี), ภาพหมุน 360° (ลากเปลี่ยนเฟรม + ซูม/เลื่อน), รูปภาพ
- หลังบ้าน **Media Studio**: เลือก/อัปโหลดสื่อ + พรีวิวสดตาม variant, ปุ่ม "3D" ต่อ variant/option ตั้งผลต่อภาพ
- Fallback 2D อัตโนมัติเมื่อไม่มี WebGL / โหลดพลาด, เคารพ `prefers-reduced-motion`

> DB เดิมจาก P0: `npm run db:reset` เพื่อได้ข้อมูลตัวอย่างพร้อม 3D

## ทำแล้ว (P2 · เดินชมร้าน)
- ปุ่ม **🚪 เดินเข้าร้าน 3D** (ลิงก์ `/<ร้าน>#walk`): เปิดประตูเข้าร้าน เดินผ่านโซน (หน้าร้าน → เคาน์เตอร์ → ตู้ → ชั้นวาง → โต๊ะ)
- เลื่อน/ปัด = เดิน · ลาก = มองรอบ · ชี้สินค้า = ป้ายชื่อ+ราคา · แตะ = เปิดดู 3D และสั่งได้ทันที · Esc/ปุ่ม Back = ออก
- แม่แบบ 3 แบบ (คาเฟ่, ร้านอาหาร, ร้านค้า) สร้างด้วยโค้ด ไม่ต้องมีไฟล์ · ใช้สีธีมร้าน · ป้ายร้าน/เมนูบอร์ดดึงจากข้อมูลจริง
- **แสงตามเวลาจริง**: ร้านปิด → ไฟหรี่ ท้องฟ้ากลางคืน ป้าย CLOSED
- หลังบ้าน **ฉากร้าน 3D**: เลือกแม่แบบ, สีผนัง/พื้น, จัดวางสินค้ารายช่อง (อัตโนมัติ/เว้นว่าง/เลือกเอง) พร้อมพรีวิวสด
- กระจายสินค้าทุกโซนอัตโนมัติ และเติมซ้ำให้ชั้นดูเต็ม

## ทำแล้ว (P3 · หน้าร้านจริง)
- **Realtime** ด้วย Postgres LISTEN/NOTIFY + Server-Sent Events (ใช้ได้ทั้ง PGlite และ Postgres หลายเครื่อง) — ออเดอร์ใหม่/เปลี่ยนสถานะเด้งทันที ไม่ต้องรีเฟรช
- **จอครัว (KDS)**: รอทำ → กำลังทำ → พร้อมเสิร์ฟ, เวลารอแต่ละบิล (เหลือง 10 นาที, แดง 20 นาที), เสียงแจ้งเตือน, โหมดเต็มจอ
- **QR สั่งจากโต๊ะ**: สร้างโต๊ะ (`A1-A6, B1`), พิมพ์ QR, เปลี่ยน QR ได้ — เลขโต๊ะผูกกับ token จาก server เท่านั้น
- **วิธีจ่าย**: PromptPay QR หรือ จ่ายที่เคาน์เตอร์ (ครัวเริ่มทำได้ทันที)
- **แจ้งเตือน LINE** (Messaging API) เมื่อมีออเดอร์ใหม่/รับเงิน · token เก็บฝั่ง server ไม่ส่งไป browser
- **พนักงานแยกสิทธิ์**: เจ้าของ / ผู้จัดการ / แคชเชียร์ / ครัว · รหัสผ่าน scrypt · ไม่มีสิทธิ์ = 404

## Production
ตั้ง `DATABASE_URL` (Supabase Postgres), `ADMIN_PASSWORD`, `AUTH_SECRET`, `SITE_URL` (ใช้สร้าง QR โต๊ะ) แล้ว `npm run db:migrate && npm run build`
